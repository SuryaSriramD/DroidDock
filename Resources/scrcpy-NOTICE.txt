The app's independent Swift client implements the protocol described by the
following pinned sources (the scrcpy desktop application is not bundled):
https://github.com/Genymobile/scrcpy/blob/v3.3.3/app/src/control_msg.c
https://github.com/Genymobile/scrcpy/blob/v3.3.3/app/src/control_msg.h
https://github.com/Genymobile/scrcpy/blob/v3.3.3/server/src/main/java/com/genymobile/scrcpy/device/DesktopConnection.java
https://github.com/Genymobile/scrcpy/blob/v3.3.3/server/src/main/java/com/genymobile/scrcpy/device/Streamer.java

The protocol is internal to scrcpy and version-specific. Server changes require
review of these layouts, updated protocol tests, and a new checksum pin.
